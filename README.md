# Hair Studio MAGIC — Струмица

Веб-сајт за **Hair Studio MAGIC**, студио за фризури, боење и шминка на Марјан Петров.
React 18 · Vite · Framer Motion. Македонски и англиски. Десктоп, таблет и мобилна верзија.

**Live:** https://davidnnv.github.io/hair-studio-magic/

## Секции
- **Hero** — златно „MAGIC“ во позадина, анимиран наслов, паралакс фотографии, златна прашина, ротирачки беџ
- **Услуги** — Фризури, Боење (Sombre, Vibrance Gloss), Шминка; фотографијата се менува при поминување
- **Запознај го сопственикот** — колаж со паралакс, златна рамка што се исцртува, огромно име во позадина, потпис, бројачи, „Зад столицата“ лента со фотографии што се влече
- **Портфолио** — филтри (Боја / Фризури / Шминка) и лајтбокс (стрелки, Esc, swipe)
- **Google оценка** 4,8 ★ со линк кон рецензиите
- **Контакт** — само со закажан термин, телефон, адреса, насоки, Instagram, Facebook и мапа

## Старт
```bash
npm install
npm run dev     # http://localhost:5173
npm run build   # dist/
```

## Уредување
- Текстови, телефон, адреса, линкови: `src/lib/content.js`
- Фотографии: `public/img/` (за замена стави нова датотека со исто име)
- Бои и фонтови: врвот на `src/styles.css`

## Објавување
Секој push на `main` се објавува на GitHub Pages (`.github/workflows/deploy.yml`).
Еднаш: **Settings → Pages → Source: GitHub Actions**.
